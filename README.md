# Portfolio Website V8

Um portfólio profissional desenvolvido com foco em experiência moderna, arquitetura escalável, acessibilidade, performance e qualidade de código.

O projeto foi concebido não apenas como uma landing page de apresentação profissional, mas também como uma demonstração prática de boas práticas de engenharia frontend moderna utilizando React 19 e TypeScript.

---

# Objetivo do Projeto

Este projeto tem como finalidade demonstrar:

- Arquitetura frontend escalável
- Organização baseada em Atomic Design
- Qualidade de código e padronização
- Boas práticas de acessibilidade
- SEO técnico
- Internacionalização
- Experiência visual moderna
- Testes automatizados
- Performance e experiência do usuário

# Arquitetura do Projeto

O projeto segue uma arquitetura baseada em Atomic Design visando escalabilidade, reutilização e manutenção.

```
src/
├── assets/
├── components/
│   ├── atoms/
│   ├── molecules/
│   ├── organisms/
│   └── templates/
├── pages/
├── services/
├── hooks/
├── styles/
├── translations/
├── tests/
├── utils/
├── constants/
├── routes/
└── types/
```
